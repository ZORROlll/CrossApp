# CrossApp

## Предметна область: Бібліотека
### Сутності:
1. Publication (видання / книга)
2. BookCopy (фізичний примірник)
3. Reader (читач)
4. Loan (видача книги)

### Призначення застосунку:
Застосунок призначений для автоматизації обліку бібліотечного фонду, відстеження наявності примірників та реєстрації видачі й повернення книг читачами.

## Додаткові завдання

### 1. Порівняння розмірів Self-Contained під різні RID
* `win-x64` (`dist/scd-win`): **71 MB**
* `linux-x64` (`dist/scd-linux`): **71 MB**

### 2. Прапорець командного рядка --json
* Запуск без аргументів (`dotnet run --project src/Cli`): виводить форматовану консольну таблицю.
* Запуск з прапорцем (`dotnet run --project src/Cli -- --json`): виводить дані одним структурованим JSON-рядком (`System.Text.Json`).

### 3. Порівняння виконання в Docker vs Windows
* **Windows (локально):** `OSDescription = Microsoft Windows 10.0.26200`
* **Docker Container (`mcr.microsoft.com/dotnet/sdk:8.0`):** `OSDescription = Linux 5.15.x (Debian GNU/Linux 12)`
* **Висновок:** Завдяки крос-платформності .NET 8 скомпільований код успішно виконується в оточенні ядра Linux без внесення будь-яких змін у код програми.
